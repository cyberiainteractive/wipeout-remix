# Wipeout Remix Toolkit
Tools to modify various aspects of Wipeout Rewrite / Remix.

## bin2qoa
A Python script that automatically converts your Wipeout 1-3 tracks to .qoa files from your legal original Playstation backups. Put them in the same file as the Python script, run it, wait, and you're done!

## CMPal
A Python toolkit for extracting textures from .CMP files, as well as creating new .CMP files automatically from folders containing PNGs. Soon to be merged with obj2prm

## obj2prm
Basic .obj to .prm conversion utility. Doesn't handle textures at the moment (see above).
